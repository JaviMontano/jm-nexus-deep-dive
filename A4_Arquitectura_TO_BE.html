Arquitectura TO-BE — Nexus Assistant OS

4 planos + 2 transversales, 8 principios arquitectónicos

01 Topología Visual

P1 PLANO INGESTA — Edge
Telegram Webhook → Cloud Function ACK <2 s → CP1 Sanitization → Audio? → Whisper (chunk >60 s) → Debounce 2 s → Pub/Sub
P2 PLANO CONTROL
Worker → CP2 Hardening → Semantic Router (Groq → OpenRouter → Gemini) → Context Retrieval → Prompt Composer → Delegation Single 15 s · Terna 30 s · Committee 60 s → Degradation Cascade
P3 PLANO EJECUCIÓN

CP1 (hard) · CP2 (hard) · CP3 (soft)
T2 TRANSVERSAL — OBSERVABILIDAD
Token Tracking · Structured Logging · Circuit Breakers

02 8 Principios Arquitectónicos

01

Async-First

Operación >5 s vía Pub/Sub. ACK <2 s obligatorio.

Previene: Webhook timeout síncrono

02

State Machine

Cada mensaje transiciona estado. Sin loops.

Previene: Agent loop infinito

03

Context Compression

Max 500 tokens + 15 turns. CRON nocturno de limpieza.

Previene: Context bloat ($$$)

04

Execution Isolation

IAM mínimo. Researcher: read-only.

Previene: Privilege escalation

05

Declarative Agents

agent.md + skill.yaml. Sin código hardcoded.

Previene: Hardcoded logic

06

Idempotent Handlers

Deduplicar por update_id en cada handler.

Previene: Acciones duplicadas

07

Fail-Open / Fail-Closed

Reads degradan (open). Writes bloquean (closed).

Previene: Estado corrupto

08

Token Budget

Single = 4 K, Terna = 12 K, Committee = 20 K.

Previene: Costos impredecibles

04 16 Casos Borde Documentados

CB-01 · Audio >60 s sin segmentación
Resolución: Whisper chunk automático en fragmentos de 60 s con overlap de 2 s. Reensamblaje por timestamp en el worker.
CB-02 · Webhook timeout (>2 s)
Resolución: ACK inmediato (200 OK vacío). Procesamiento diferido vía Pub/Sub. Retry automático con backoff exponencial.
CB-03 · Mensajes duplicados (Telegram retry)
Resolución: Deduplicación por update_id en Firestore con TTL de 24 h. Handler idempotente.
CB-04 · Fallo del proveedor LLM primario
Resolución: Cascada de degradación: Groq → OpenRouter → Gemini. Circuit breaker con umbral de 3 fallos / 60 s.
CB-05 · Context window overflow
Resolución: Compresión progresiva: resumen de turns >15. CRON nocturno borra contexto inactivo >72 h. Fallback: truncar a 500 tokens.
CB-06 · Agent loop infinito
Resolución: Max 5 transiciones por mensaje. State machine rechaza loops detectados (mismo estado ≥2 veces). Kill switch manual en Firestore.
CB-07 · Tool sin permiso (L3/L4)
Resolución: Permission Gate retorna error estructurado. Agente recibe alternativa sugerida. Log de auditoría registra intento.
CB-08 · HIL timeout (TTL 24 h)
Resolución: Acción pendiente expira automáticamente. Notificación al usuario. Estado revierte a pre-acción. Registro en audit_log.
CB-09 · Injection en input de usuario
Resolución: CP1 Sanitization (hard): regex + deny-list + length cap (4 096 chars). Entradas sospechosas a cuarentena con flag needs_review.
CB-10 · Output con PII / datos sensibles
Resolución: CP3 Output Scan (soft): regex para emails, teléfonos, tarjetas. Redacción automática con [REDACTED]. Log de incidencias.
CB-11 · Firestore write conflict
Resolución: Transacciones atómicas con retry (max 3). Versionado optimista con campo _version. Fail-closed: no escribe si conflicto persiste.
CB-12 · Cloud Storage URL expirada
Resolución: Signed URLs con TTL 7 d. Regeneración bajo demanda si el usuario solicita recurso expirado. Cleanup CRON semanal.
CB-13 · Ráfaga de mensajes (flood)
Resolución: Debounce 2 s agrupa mensajes consecutivos. Rate limiter: max 10 msg/min por usuario. Exceso encolado con prioridad baja.
CB-14 · Terna sin consenso
Resolución: Si 3 agentes divergen, Coordinator selecciona por score de confianza. Si todos <0.6, escalado a Committee (60 s budget).
CB-15 · Budget de tokens excedido mid-request
Resolución: Token counter pre-flight. Si estimación >budget, downgrade automático (Committee → Terna → Single). Notificación al usuario.
CB-16 · Skill YAML inválido en runtime
Resolución: Validación JSON Schema al cargar. Skill inválido se desactiva (no crash). Alerta en canal de ops. Fallback a skill genérico.
