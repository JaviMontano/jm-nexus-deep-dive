A7 · Roadmap 3 Horizontes

Roadmap Critico — Nexus Assistant OS

3 horizontes, 14 sprints, 3 gates

1 Vista Timeline

W1 – W4 H1 · SOLIDIFICAR CORE 4 sprints
W5 – W10 H2 · EXPANDIR CAPACIDADES 5 sprints
W11 – W16 H3 · ESCALAR 4 sprints

2 H1 — Solidificar Core H1 · W1-4

S1 · W1-2 G-06 CRIT

Project State Engine

Gherkin: Dado proyecto inactivo 30d, cuando operador envia “retoma proyecto X”, entonces recupera compressed_context <500 tokens, inyecta en prompt, responde <3s.
Casos borde: nombre ambiguo (pedir clarificacion) • context corrupto (degradar gracefully)
S2 · W2-3 G-05 CRIT

HIL Middleware

Gherkin: Agente propone accion → crea pending_action → botones Inline → aprobacion → ejecuta. 0 false positives.
Casos borde: approval post-TTL (re-proponer) • doble click (idempotencia)
S3 · W3-4 G-07 ALTA

Artifact Versioning

Gherkin: Genera HTML, sube Storage, URL firmada 7d, versiona, asocia a proyecto.
Casos borde: generacion parcial (no guardar) • storage quota (notificar)
S4 · W4 G-02 + ADR-006

Memory Enhancement + Token Budget

Gherkin: TTL funcional, CRON comprime a ≤500 tokens, compression_log, budget enforced.
Casos borde: CRON falla (rollback transaction) • budget excedido 200% (truncar agresivo)
G1
Gate H1 — Criterios de Paso
  • 10 HTML consecutivos generados via voz
  • Contexto recuperado tras 5+ dias de inactividad
  • 3 acciones L2 aprobadas via HIL
  • 0 acciones ejecutadas sin aprobacion
  • Budget enforced >90% del tiempo

3 H2 — Expandir Capacidades H2 · W5-10

S5-6 · W5-7 G-08

Google Tasks + Calendar

Integracion bidireccional con Google Tasks y Calendar. CRUD completo con aprobacion L2 para escrituras.
S7-8 · W7-9 G-12

Deep Research Pipeline

Pipeline de investigacion profunda con fuentes multiples, sintesis y citacion. Sin loops infinitos.
S8 · W8 G-09

n8n Spike

Spike de evaluacion: viabilidad de n8n como orquestador de workflows. Decision documentada Go/No-Go.
S9-10 · W9-10 G-11

Observability Dashboard

Dashboard operacional: metricas de uso, latencia, errores, costos token. Alertas configurables.
G2
Gate H2 — Criterios de Paso
  • GTasks + Calendar funcional con aprobacion L2
  • Research pipeline sin loops infinitos
  • Dashboard operacional desplegado
  • Decision n8n documentada (ADR)

4 H3 — Escalar H3 · W11-16

S10-11 · W11-13 G-10

Multi-Tenant Isolation

Aislamiento completo entre tenants: datos, configuraciones, memory stores. Row-level security.
S12 · W13 G-02

Vector DB Integration

Memoria semantica via embeddings. Busqueda por similaridad para contexto enriquecido. Integracion con Memory Engine.
S13-14 · W14-16 G-08

B2B Packaging + Gmail

Empaquetamiento B2B: onboarding, billing, limites por plan. Integracion Gmail para operadores.
G3
Gate H3 — Criterios de Paso
  • Operador B2B genera propuestas sin ver datos del fundador
  • Billing activo y funcional
  • Vector DB integrado con memory engine
  • Gmail operativo con aprobacion L2
